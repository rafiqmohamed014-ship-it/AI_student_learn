Explain recursion in simple words.

Recursion is a function that solves a problem by calling itself on a smaller version of the same problem.

Think of unpacking nested boxes: you open the outer box, find another box inside, and open that one too — until you find the toy (your base case).

Two rules make it work: a base case that stops the loop, and a recursive call that moves strictly closer to it.

FAQ

Honest answers

Is the AI a real model?

Yes. It calls a real language model through a small server that you run. If no API key is configured the app tells you so plainly instead of faking replies.

Where is my data stored?

Locally in your browser by default. Add Supabase and it moves to a real database with Row Level Security, so only you can read your rows.

Do I need to pay?

No paid service is required. The app, the lessons and the offline quiz engine are free. An AI API key is optional — you can use any provider, including a free tier or a local model.

Will it write my essay for me?

It is tuned to teach rather than hand over finished work. If you ask for an assignment, it explains the concept and gives you something to adapt instead.
